# Roadmap

What is next for Corgi, in order. Each item ships with tests and a doc before it counts.

## Done recently

- Helpers ("ajudantes"): see [docs/HELPERS.md](docs/HELPERS.md). Next for them: a daily digest option
  and watches on app data as triggers.
- Navigation: Chat · Atividade (Ideias inside) · Rotinas · Ajustes; the menu lists conversations.

## Next

- [ ] **Pulse**: a short check every 30–60 minutes in working hours that speaks only when something
      needs you, replacing today's Ideas refresh.

## Later

- [ ] "When X shows up, do Y" standing intents (keyword-matched, with cooldown and expiry).
- [ ] Watches on app data (a Notion status changed, an e-mail from someone arrived), not only pages.
- [ ] Skills Corgi proposes after repeated work, applied only after you review them.
- [ ] Semantic memory search (embeddings) if keyword recall stops being enough.
- [ ] Headed browser on the server (Xvfb) for sites that block headless browsers.
- [ ] Native iPhone app through TestFlight.
